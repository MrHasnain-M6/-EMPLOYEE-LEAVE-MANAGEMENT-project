1. Introduction

The Employee Leave Management System is a Python-based application designed to manage employee leave requests and leave balances.

It allows employees to apply for leave, check their remaining leave balance, and get their leave requests approved or rejected automatically based on available leave days.

2. Features

* Apply for employee leave.
* View remaining leave balance.
* Support three types of leave:
    * Casual Leave
    * Sick Leave
    * Earned Leave
* Automatic leave-day calculation.
* Date format validation.
* Automatic leave approval or rejection.
* Automatic deduction of approved leave days.

3. Technologies Used

* Python 3
* Datetime Module
* Dictionary and Nested Dictionary
* Functions
* Loops and Conditional Statements
* Exception Handling

8. Python Concepts Used

* Dictionary: Stores employee leave information.
* Nested Dictionary: Stores different leave balances for each employee.
* Functions: Organizes the program into reusable blocks.
* If-Else: Checks leave availability and validates input.
* Loops: Repeats the main menu.
* Datetime: Calculates leave duration.
* Try-Except: Handles invalid date formats.

9. Conclusion

The Employee Leave Management System provides a simple way to manage employee leave requests using Python. It reduces manual calculations, maintains leave balances during program execution, and automatically approves or rejects leave requests.
